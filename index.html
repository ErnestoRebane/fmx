    Details
    
        
    
        
    
          
    Back to stock
    
          
    Get FM-1 V15 from m-vave.com (Downloads → PC Firmware → FM-1 V15) and choose its FM-1.fwsc here. The app checks it is the real V15 before it sends anything; the file stays in this browser.
    
          
    The stock firmware can't open FMX's songs or sounds: back up the set first (Sounds, below), and restore it after you come back to FMX.
    
          
          
    
            
            
          
    
          
          
    
          
    If it won't start
    
          
    Hold OCT− while you switch the FM-1 on. It starts in USB rescue, and you can install again from here.
